# Домашняя страница WebGAL

[Домашняя страница WebGAL](https://openwebgal.com)

## Как запустить

``` shell
npm i && npm run dev
```

## Улучшение или добавление переводов

Чтобы улучшить перевод, откройте папку `/locales/` и измените соответствующий JSON-файл.  
Чтобы добавить переводы, измените `/i18n.ts` и добавьте соответствующий JSON-файл в папку `/locales/`, откройте `/app/page.tsx` и измените скрипт с id redirect.

## Добавление демонстрационной игры

Откройте `/data/games.ts` и добавьте игру.

## Добавление спонсоров

Откройте `/data/sponsors.ts` и отредактируйте его.

## Обновление списка участников

Запустите `node update-contributors.js`.
